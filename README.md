# Dopbase

Dopbase is an open-source secrets manager designed to run as one executable. The project is currently pre-release.

Public product documentation lives in [`docs/`](./docs).

## Documentation

Install dependencies with Bun, then start the VitePress site:

```bash
bun install
bun run docs:dev
```

Build and preview the production documentation:

```bash
bun run docs:build
bun run docs:preview
```

The documentation describes the intended v0.1 interface and marks unfinished commands and services as planned.
